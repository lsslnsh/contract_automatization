# Заполнение договоров и актов на Python

Программа создаёт договор и акт в формате Word для физлица на консультационные услуги ЛСК (личная стратегическая консультация), аудит или Сопровождение. Данные заказа сохраняются в JSON между запусками. В примерах используются вымышленные реквизиты.

## Установка

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

Windows (PowerShell):

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```
## Файлы

- `main.py` запрашивает данные и создаёт документы.
- `input/prices.json` актуальные цены на услуги и финальную стоимость с учетом процентов за налоги УСН.
- `provider_data/provider.example.json` содержат реквизиты Исполнителя. Реальные реквизиты Исполнителя `provider.json` исключены из Git.
- `templates_fiz/` содержит шаблоны документов: три варианта договора услуг и акт выполненных работ.
- `input/examples/` содержит вымышленные реквизиты Заказчикоа
- `run_example.py` запускает тестовое создание договоров.
- `output/` хранит готовые документы DOCX.
- `data/` содержит JSON с данными обработанных заказов. 

## Запуск вручную

Запустите `main.py`, выберите `лск`, `аудит` или `сопровождение`. Вставьте восемь полей, каждое с новой строки, без подписей:

```text
ФИО
Серия и номер паспорта
Кем выдан паспорт
Дата выдачи паспорта
Код подразделения
Адрес регистрации
Телефон
Почта
КОНЕЦ
```

Затем введите дату договора и дату проведения или начала услуги в формате `ДД.ММ.ГГГГ`. Для сопровождения укажите количество встреч, каждая длится 1,5 часа.

## Проверка без ручного ввода

Вместо `main.py` запустите нужный тестовый файл:

На MacOS:
```bash
.venv/bin/python run_example.py lsk
.venv/bin/python run_example.py audit
.venv/bin/python run_example.py support
.venv/bin/python run_example.py dirty
```

На Windows:
```bash
.venv\Scripts\python.exe run_example.py lsk
.venv\Scripts\python.exe run_example.py audit
.venv\Scripts\python.exe run_example.py support
.venv\Scripts\python.exe run_example.py dirty
```

Результаты появляются в `output/`.

## Грязные данные и ошибки

Программа принимает без ошибки и исправляет: 
– Лишние пробелы в ФИО и паспорте, код подразделения без дефиса. Отчество необязательно, международный код при вводе телефона допускается.

Ошибки, которые просит исправить:
– Отсутствие данных: просит повторить весь блок с реквизитами.
– Одно слово в ФИО, неверный серия/номер паспорта или код подразделения, пустой адрес или орган выдачи, буквы в телефоне: повторно запрашивает конкретное поле. 
– Неверная почта (лишний @, пробелы и двойная точка): просит заново ввести электронный адрес. 
– Несуществующая дата, дата проведения услуги раньше даты договора, неизвестная услуга, отрицательное или дробное число встреч в рамках Сопровождения: повторно запрашивает значение. 
– Отсутствие файла, цены, повреждённый DOCX, ошибка в полях шаблона: выводит причину "Исправьте файл и перезапустите программу".
– В примере недостаточно данных: сообщает о незавершённом вводе, просит дополнить пример.
– Ошибка записи: удаляет новые неполные файлы, при неудачном удалении сообщает их пути. 
– Создание документа DOCX или JSON с именем, уже существующим в output: cохраняет прежние файлы, а для нового просит изменить ФИО.
